## 5. 编译器行为记录（供 R4 与后续补采参考）

1. `locate()` 只把「keyword 是 canonical 文件路径子串」的条目当 hint；无 hint 则 fallback 到 README.md。纯正文短语永远采不到非 README 文档——这是前两轮 herdr-M5 / loop-now-M5 失败的根因。
2. `excerptForCriterion()` 取选中文件里**第一条**含任一 keyword 的行（前1后5行窗口，截断 2000 字符）。一个 criterion 的多个 keyword 里，谁先命中文档正文谁决定 excerpt。
3. 路径导航 keyword（如 `AGENTS.md`、`guide/concepts.md`）能强制 locate 到目标文档，但会让该 criterion 在**所有仓库**都定位到同名文件 → 跨仓库噪声（本轮 B4 的错配条目即此）。用法：单仓库专项 brief，路径 keyword 只用在该仓库目标文件唯一命中的子串。
4. `resolveRevision()` 只钉默认分支 HEAD、忽略 brief 的 revision/pin（见 `2026-11-16-sealed-resupply-blocked.md`）。
